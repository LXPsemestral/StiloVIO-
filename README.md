# StiloVIO — Tienda de ropa

Proyecto en HTML, CSS y JavaScript. Abre `index.html` con Live Server en VS Code.

# Páginas
- `index.html`: portada con fotografías y productos destacados.
- `productos.html`: catálogo dinámico de doce productos.
- `contacto.html`: formulario con validaciones en tiempo real.
- `carrito.html`: carrito de demostración guardado en el navegador.

# Fotografías y catálogo
Las fotografías JPG provienen del ZIP de imágenes entregados por nosotros. Los nombres y precios de los productos provienen de `Productos.js`. 

# Organización del equipo
- HTML e imágenes: `index.html`, `productos.html`, `contacto.html`, `carrito.html`, `img/`.
- CSS: `css/estilos.css`.
- JavaScript: `js/productos.js`, `js/carrito.js`, `js/contacto.js`.
- Git y pruebas: `README.md`, `PRESENTACION.md`, `PRUEBAS.md`.

# Limitaciones
El carrito no cobra y el formulario no envía correos.
